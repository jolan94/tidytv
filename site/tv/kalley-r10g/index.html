Debloat the Kalley R10G

Google TV 14 · 14 apps on the list · tested on a real set

The R10G ships with Google partner setup and store plumbing, a Seraphic interactive app, and a Realtek karaoke app with its user guide. It also has preloaded apps this set does not use, including Apple TV, Claro TV, Kick, JioTV, CBS, Prime Video, Bombsquad and Crossy Road, plus YouTube Music.

This list was tested on one set on 19 and 20 October 2026, with its new home screen installed. Netflix, Disney+, Max, Spotify, YouTube, Twitch, GeForce NOW and Stremio still opened, and HDMI input, Home and the Input button all worked. TidyTV turns these items off from your phone over Wi-Fi, saves a backup first and deletes nothing.

What always stays on

  • Live TV and the other TV inputs, including HDMI.
  • TV firmware updates.
  • Remote firmware updates, which also update the remote.
  • Netflix, Disney+, Max, Spotify, YouTube, Twitch, GeForce NOW and Stremio, which still opened in testing.

Good to know on this model

  • The remote's Input button sends a different key code from most remotes. Check that it still works after the change.
  • This list is fresh and has not been lived with for days. If something breaks, turn that app back on with its switch.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Will the Input button still work on my Kalley R10G?

In testing, the Input button and HDMI input both still worked after the change. Check it on your own set, because this remote sends a different key code.

Do my streaming apps still work?

In testing, Netflix, Disney+, Max, Spotify, YouTube, Twitch, GeForce NOW and Stremio all still opened. Only the apps marked as unused are turned off.

Will I still get firmware updates?

Yes. The TV's update service and the remote's update service are both kept on.
