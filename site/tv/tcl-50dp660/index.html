Debloat the TCL 50DP660

Android TV 8.0 · 26 apps on the list · tested on a real set

This European TCL runs Android TV 8.0. The stock home carries recommendation rows and T-Channel content tiles. It also has TCL's MagiConnect mirroring, an Alexa bridge, an app store, a media centre and start-up service, factory test leftovers, and Google extras such as Play Movies and games.

The list was applied on a real TV and survived several reboots. TidyTV turns the apps off from your phone over Wi-Fi, saves a backup first and never deletes anything, so each one can be switched back on. The Live TV, tuner, HDMI and AV apps are kept.

Good to know on this model

  • This set has no microphone, so Assistant and voice search are on the list.
  • Never use the factory menu's NVM reset. It wipes the Wi-Fi address and Netflix identity, and only a full firmware reflash fixes it.
  • The stock home has priority on this firmware, so a replacement home screen only takes over once the stock one is off.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Will the voice button still work on my TCL 50DP660?

This set has no microphone, so there is no voice button to lose.

Does casting still work?

Chromecast is kept. MagiConnect screen mirroring is on the list and is switched off.

Will TV updates still work?

The TCL OTA updater is on the list. Turn it back on in the app when you want to check for a firmware update.
