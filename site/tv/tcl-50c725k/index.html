Debloat the TCL 50C725K

Android TV 11 · 22 apps on the list · tested on a real set

This TCL runs Android TV 11 with 2 GB of memory. It ships with TCL pushing content to the home screen, TCL Live FAST channels, app promos in the TCL menu, a store demo sticker, TCL notifications and TCL analytics. Partner apps install themselves silently, and preloaded browsers, a gallery and a voice assistant use memory too.

The list was applied on a real unit and survived a reboot. TidyTV turns the apps off from your phone over Wi-Fi, saves a backup first and never deletes anything, so each one can be switched back on. The TCL system apps that run the remote and inputs are kept.

Good to know on this model

  • Google voice assistant uses about 175 MB of memory and is off by choice. Switch it back on in the app if you use voice.
  • Several apps, such as the browser and the screen reader, are off by choice.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Will the voice button still work on my TCL 50C725K?

Not with the default list, which turns off the Google voice assistant by choice. Switch it back on in the app if you use voice.

Does casting still work?

Yes. Chromecast and TCL mirroring are kept.

Will TV updates still work?

Yes. TCL's firmware updater is kept.
