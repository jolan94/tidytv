Debloat the Kogan Google TV GTVU65KG

Google TV 14 · 12 apps on the list · tested on a real set

This Kogan set is built by Changhong and ships with telemetry and ad services, a Changhong store and help app, and several preloaded apps. The list also turns off streaming apps that this home did not use, and each one has its own switch in the app.

It was tested on one set on the same day. Home, the Input key with Live TV and both HDMI inputs, and Netflix all kept working, and the list stayed off after a restart. TidyTV turns these off from your phone over Wi-Fi, saves a backup first and never deletes anything.

Good to know on this model

  • TidyTV only cleans up the apps on this set. The Google TV home screen stays, and so does its setup helper.
  • The AirPlay receiver is kept. Switch it off in the app if nobody uses AirPlay.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Does casting still work on my Kogan?

Yes. Chromecast and the AirPlay receiver are both kept, so you can cast from Android and from an iPhone.

Will the Input key and HDMI still work?

Yes. After each batch in testing, the Input key opened the switcher with Live TV and both HDMI inputs.

Can I get everything back?

Yes. Restore everything turns every app back on in one tap. Nothing is deleted.
