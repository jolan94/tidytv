Debloat the XGIMI Horizon S Pro

Android TV 11 · 22 apps on the list · tested on a real set

The XGIMI Horizon S Pro projector comes with a store demo, factory burn-in and Wi-Fi check tools that run at boot, a bug report uploader, Google feedback and recommendation rows, a file manager, a music app and an animated screensaver. A projector at home has no use for most of them.

This list was tested on a real unit, and the result was checked again after a restart. The projector's keystone, focus, autofocus, remote and Bluetooth services are not on the list at all, and the HDMI 1 input is kept. TidyTV turns these apps off from your phone over Wi-Fi, saves a backup first and never uninstalls anything.

What always stays on

  • Keystone, focus and autofocus services, which the projector needs
  • HDMI 1 and its player
  • Bluetooth remote and speaker mode
  • The remote keys, brightness and core XGIMI system services
  • The first-boot setup wizard, kept on purpose

Good to know on this model

  • Only HDMI 1 shows as an input on this projector, so the other input labels will not appear.
  • The default screensaver is off in this list. Choose another screensaver in the TV's settings, or the projector has nothing to show while idle.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Will the HDMI input still work?

Yes. HDMI 1 is kept along with its player and input service. It is the only input this projector shows.

Does casting still work?

Chromecast built-in is off by choice in this list, so turn it back on in the app if you cast to this projector.

Will it stop the ads on the home screen?

It turns off Google's recommendation rows and the Backdrop screensaver, along with several streaming apps. Other parts of the home screen are not on this list.
