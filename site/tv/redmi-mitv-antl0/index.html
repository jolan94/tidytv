Debloat the Redmi TV (MiTV-ANTL0)

Android 5.1 · 11 apps on the list · tested on a real set

This Redmi TV runs Chinese-market firmware on Android 5.1, with no Google services at all. It ships with Xiaomi's quality and analytics uploaders, a promo renderer that also fetches screensaver ads, and a cloud service that can push apps to the TV remotely. There is also a shopping plugin, a cleaner app and a game SDK.

Every app on this list was checked on the TV itself before it was listed, so the names match this firmware. TidyTV turns these off from your phone over Wi-Fi. It saves a backup first, switches each app off in Android's own settings and never uninstalls it. Restore everything switches them all back on in one tap.

What always stays on

  • The Sogou TV keyboard. It is the only input method on this firmware, so the list leaves it on.

Good to know on this model

  • This firmware has no Google services, so there is no Google Play Store on it.
  • The boot-up video ad is a system setting rather than an app, so turning off apps does not remove it.
  • The update service is off in this list, so firmware updates stop too, including security updates. Turn it back on for a while when you want an update.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Will it stop the ads on the home screen?

Mostly. It turns off the promo renderer that fetches screensaver ads, and the cloud service that pushes apps. The boot-up video ad is a system setting, so it stays until that setting is changed.

Will it still get firmware updates?

Not while the update service is off. Switch it back on in the app when you want an update, and off again afterwards.

Can I get the old home screen back?

Yes. Restore everything turns every app back on and puts the old home screen back in one tap.
