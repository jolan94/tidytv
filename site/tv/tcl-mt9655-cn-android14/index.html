Debloat the TCL / FFalcon MT9655 (China 2026)

Android 14 (China) · 27 apps on the list · tested on a real set

This China-market TCL, also sold under the FFalcon name, reports ad and telemetry data and carries optional home widgets and content apps. The list covers those, plus a few optional extras you can leave on. Each app has its own switch in the app, so you decide which ones to turn off.

This model is harder to set up than others. It has no Developer options screen and no Wireless debugging row, because TCL replaced the Settings app. TidyTV needs the TV's own ADB switch, which opens a secure connection on a random port each time. TidyTV turns these apps off from your phone over Wi-Fi, saves a backup first and never deletes anything.

What always stays on

  • The TV's own settings app
  • Remote pairing and the remote keys
  • Live TV and HDMI inputs
  • The home screen unless you pick a new one

Good to know on this model

  • There is no Developer options screen. The only switch is under General Settings, More, ADB, and it picks a new port every time.
  • Because of that secure connection, setup may not work with the phone app the same way as on other TVs.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Can I get the old home screen back on my TCL / FFalcon MT9655?

Yes. Restore everything in the app turns every app back on and puts the old home screen back in one tap. TidyTV only switches apps off, so nothing is ever deleted.

Can TidyTV connect to this TV?

Possibly not the usual way. This firmware has no Wireless debugging screen, and its ADB switch opens a secure connection on a random port, so setup is harder than on other models.

Does TidyTV delete anything on my TCL / FFalcon MT9655?

No. It turns apps off with Android's own setting, saves a backup first and checks each one. You can turn any app back on with its switch.
